# ZenDrift

A simple ZenDrift orchestrator for predictive maintenance.

With ZenDrift, you get a lightweight tool that stays out of your way.

**What you get**

- A simple ZenDrift orchestrator for predictive maintenance

## Key Features

- A simple ZenDrift orchestrator for predictive maintenance

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ZenDrift.git`
2. `cd ZenDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

ZenDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
